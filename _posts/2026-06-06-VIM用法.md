下面是一份AI整理的图解风格的vim常用命令指南，带视觉化理解、结构清晰、超级容易记住。

🎯 vim 图解：模式结构（最重要的概念）
![](https://image.olim.in/2026/vim-modes-1.png)
![](https://image.olim.in/2026/vim-modes-2.png)

vim 只有三个你真正需要记住的模式：

Normal 模式：移动、删除、复制（默认模式）

Insert 模式：输入文字

Visual 模式：选中一段文本

切换方式：

Normal → Insert：按 i / a / o

Insert → Normal：按 Esc

Normal → Visual：按 v

🎉 最简单的 vim 生存口诀（图解版）

i 输入 → Esc 退出 → :wq 保存退出 → dd 删除行 → yy 复制 → p 粘贴

掌握这句，你已经能用 vim 干活了。

下面这份 vim 进阶技巧

🟦 1. 多光标跳转（比方向键快 10 倍）

行级跳转

gg：跳到文件开头

G：跳到文件结尾

数字 + G：跳到指定行（例如 20G）

单词跳转

w：下一个单词

b：上一个单词

e：单词结尾

行内快速跳转

0：行首

$：行尾

🟩 2. 强大的可视模式（Visual Mode）

进入可视模式

v：字符模式

V：整行模式

Ctrl+v：块模式（超强）

可视模式能做什么？

选中 → d 删除

选中 → y 复制

选中 → > 缩进

选中 → < 反缩进

块模式（Ctrl+v）可以：

批量注释

批量删除列

批量插入字符

这是 vim 的杀手级功能。

🟧 3. 查找与替换（比 nano 强太多）

全文替换
`:%s/旧/新/g`

只替换当前行
`:s/旧/新/g`

替换时逐个确认
`:%s/旧/新/gc`

其中：

g = 全部

c = confirm（确认）

🟨 4. 多文件编辑（vim 也能像 IDE）

同时打开多个文件
`vim file1 file2 file3`

文件切换

:n：下一个

:N：上一个

🟪 5. 分屏（超级实用）

水平分屏
`:split filename`

垂直分屏
`:vsplit filename`

分屏切换

Ctrl + w + w：切换窗口

Ctrl + w + h/j/k/l：按方向切换

调整分屏大小

Ctrl + w + +

Ctrl + w + -

🟫 6. 宏（Macro）——重复操作神器

录制宏
`q + 字母`

例如：
`qa`
表示录制到寄存器 a。

停止录制
`q`

执行宏
`@a`

执行多次
`10@a`

适合：

批量格式化

批量插入

批量修改

🟥 7. 缓冲区（Buffer）管理

查看所有缓冲区
`:ls`

切换缓冲区
`:b 数字`

删除缓冲区
`:bd`

🟦 8. 跳转历史（像浏览器的前进/后退）

Ctrl + o：后退

Ctrl + i：前进

适合你在多个函数之间跳来跳去。

🟩 9. 标记（Mark）——给文件做书签

设置标记
`ma` m后面是标记字母，可以是ma, mb, mc等,供后面跳回到不同标记处

跳回标记
`'a` 字母就是之前标记的字母

🟧 10. 自动补全（写脚本必备）

在插入模式按：

Ctrl + n：补全单词

Ctrl + p：反向补全
